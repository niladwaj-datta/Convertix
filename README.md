## 🤔 Why Convertix?

Ever been halfway through a recipe and the oven wants °F but your brain only speaks °C?
Or tried to figure out what ₹5,000 is in euros without opening five browser tabs?

**Convertix** puts it all in one clean, fast place: everyday unit conversions *and* live-style currency exchange, with no clutter and no sign-ups.

| | Feature | What it does |

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/niladwaj-datta/Convertix

# 2. Move into the project folder
cd convertix

# 3. Install dependencies (skip if it's plain HTML/JS)
npm install

# 4. Run it
npm start
```

Then open **http://localhost:3000** in your browser. 🎉

## 🧠 How It Works

1. **Units:** every unit is converted to a *base unit* first (e.g. meters for length), then to your target unit. This means adding a new unit only takes one line.
2. **Currency:** the amount is converted using exchange rates relative to a base currency, then displayed in your chosen currency.

```
 5 miles ──► 8046.72 meters (base) ──► 8.05 kilometers
```
